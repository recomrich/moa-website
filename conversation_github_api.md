## Assistant

Voici les étapes :

**1. Connecte-toi sur** github.com

**2. Clique sur ta photo de profil** (en haut à droite) → **Settings**

**3. Descends tout en bas** du menu gauche → **Developer settings**

**4. Clique sur** → **Personal access tokens** → **Tokens (classic)**

**5. Clique sur** → **Generate new token** → **Generate new token (classic)**

**6. Remplis :**
- **Note** : `hyperliquid-bot`
- **Expiration** : 90 days (ou No expiration)
- **Coche** : ✅ `repo` (toute la section)

**7. Clique** → **Generate token**

**8. COPIE le token** (il commence par `ghp_...`) — il n'apparaît qu'une seule fois !

---

Colle-moi le token ici quand tu l'as, ainsi que ton **nom d'utilisateur GitHub**.
